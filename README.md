# theatre-app
# Рассадка зрителей

Локальное одностраничное приложение для распределения зрителей по местам в залах.
Поддерживается несколько залов с разной схемой кресел. Работает полностью офлайн,
открывается двойным щелчком по `index.html`, все данные обрабатываются локально
и никуда не отправляются.

Написано на чистых HTML + CSS + JavaScript: без фреймворков, без сборки,
без ES-модулей, без обязательного сервера. Работа с Excel — через библиотеку
SheetJS, подключённую локальным файлом `vendor/xlsx.full.min.js`.

## Состав проекта
проект/
├─ index.html — разметка интерфейса
├─ style.css — оформление, стили печати
├─ app.js — вся логика приложения
├─ README.md — этот файл
└─ vendor/
└─ xlsx.full.min.js — библиотека SheetJS 


## Установка

1. Создайте папку проекта и сохраните в неё `index.html`, `style.css`, `app.js`.
2. Создайте папку `vendor` и скачайте в неё SheetJS как `vendor/xlsx.full.min.js`:
   - официальный CDN: `https://cdn.sheetjs.com/xlsx-0.20.3/package/dist/xlsx.full.min.js`
   - зеркало: `https://cdn.jsdelivr.net/npm/xlsx@0.18.5/dist/xlsx.full.min.js`
3. (По желанию) положите рядом `favicon.svg` и подключите его в `<head>`:
   `<link rel="icon" type="image/svg+xml" href="favicon.svg">`.
4. Откройте `index.html` двойным щелчком в браузере (сервер не нужен).

## Режимы

- **Редактирование** — виден список зрителей слева, доступно назначение мест,
  добавление, правка, удаление, цвета категорий.
- **Просмотр** — только меню и план зала; можно рассматривать кресла с подсказками.

После успешных «Сохранить», «Сохранить как» и «Печать» приложение само
возвращается в режим просмотра. Перед разрушающими действиями спрашивается
подтверждение; при несохранённых изменениях браузер предупредит о закрытии.

## Выбор зала

В меню есть выпадающий список залов. Доступны пять залов:

| Зал                 | Идентификатор |
|---                  |---            |
| Театр Драмы         | `drama`       |
| Музкомедия          | `muzkomediya` |
| Филармония          | `filarmoniya` |
| КЗ «Сибирь»         | `sibir`       |
| Молодёжный театр    | `molodezhny`  |

При смене зала, если есть назначенные места, запрашивается подтверждение,
после чего назначения снимаются (список зрителей сохраняется). Выбранный зал
записывается в файл и восстанавливается при загрузке.

## Коды мест

Каждое место имеет внутренний код вида `ПРЕФИКС-РЯД-МЕСТО`, например `П-1-5`.
Префикс однозначно обозначает зону внутри выбранного зала. Коды интерпретируются
только в рамках активного зала: один и тот же префикс в разных залах — разные зоны.

- Для обычных зон код `П-1-5` читается как «Партер, ряд 1, место 5».
- Для вертикальных зон (ложи, боковые балконы) внутренне код имеет вид `ЛЛ-1-3`,
  но в интерфейсе и в Excel показывается без ряда: «Ложа левая, место 3».

Место можно задать тремя способами (все понимаются при вводе и импорте):
- короткий код: `П-1-5`, `Б-7-36`, `А-15-10`, `ЛЛ-1-3`, `В-2-3`, `П1-1-5`;
- полный текст: «Партер, ряд 1, место 5»;
- название зоны + место для вертикальных: «Балкон левый, место 7».

Совпадение имени/префикса нечувствительно к регистру и выбирается по самому
длинному совпадению, поэтому «Балкон левый» не путается с «Балкон»,
а префикс `П1` — с `П`.

### Музкомедия

| Зона | Префикс | Ряды | Нумерация | Пример кода |
|---|---|---|---|---|

Ряды Амфитеатра пронумерованы сквозным образом (13–19), продолжают Партер.

### Филармония

| Зона | Префикс | Ряды / места | Нумерация | Пример кода |
|---|---|---|---|---|
| Партер | `П` | 1–12 (21 место) | слева направо | `П-5-10` |
| Амфитеатр | `А` | 13–19 (22–24 мест) | слева направо | `А-17-12` |
| Балкон | `Б` | 1–4 (21–34 мест) | слева направо | `Б-4-20` |
| Ложа левая | `ЛЛ` | 6 мест, вертикально | сверху вниз | `ЛЛ-1-3` |
| Балкон левый | `ЛБ` | 12 мест, вертикально | место 1 снизу | `ЛБ-1-7` |
| Ложа правая | `ПЛ` | 6 мест, вертикально | сверху вниз | `ПЛ-1-3` |
| Балкон правый | `ПБ` | 12 мест, вертикально | место 1 снизу | `ПБ-1-7` |

Ложи и боковые балконы расположены по бокам от Партера и Амфитеатра.

### КЗ «Сибирь»

| Зона | Префикс | Ряды / места | Нумерация | Пример кода |
|---|---|---|---|---|
| Партер | `П` | 1–16 (14–24 мест) | **справа налево** | `П-1-24` |
| VIP-Ложа | `В` | 1–3 (6–8 мест) | **справа налево** | `В-2-3` |
| Балкон левый | `БЛ` | 13 мест, вертикально | от сцены (место 1 сверху) | `БЛ-1-5` |
| Балкон правый | `БП` | 13 мест, вертикально | от сцены (место 1 сверху) | `БП-1-5` |

Обратите внимание: в Партере и VIP-Ложе нумерация кресел идёт справа налево,
поэтому место 1 находится у правого края ряда.

### Молодёжный театр

| Зона | Префикс | Ряды / места | Нумерация | Пример кода |
|---|---|---|---|---|
| Партер | `П` | 1–16 (20–23 мест) | **справа налево** | `П-1-20` |
| Балкон | `Б` | 1–5 (22 места) | **справа налево** | `Б-3-11` |
| Ложа правая, 1 этаж | `П1` | 10 мест, вертикально | от сцены | `П1-1-5` |
| Ложа правая, 2 этаж | `П2` | 9 мест, вертикально | от сцены | `П2-1-4` |
| Ложа левая, 1 этаж | `Л1` | 10 мест, вертикально | от сцены | `Л1-1-5` |
| Ложа левая, 2 этаж | `Л2` | 9 мест, вертикально | от сцены | `Л2-1-4` |

Ложи 1-го этажа ближе к залу, 2-го этажа — дальше (симметрично слева и справа).

## Список зрителей

- Поля: **ФИО**, **категория**, **место** (или «не назначено»).
- Поиск сверху — по ФИО и категории, без учёта регистра, по частичному совпадению.
- Фильтр **«Только без места»** показывает зрителей, которым место ещё не назначено.
- Добавление вручную, редактирование, удаление (с подтверждением).
- Кнопка «Вставить список…» — массовое добавление построчно из буфера или текста.
  Формат строки: `ФИО, категория, место`; разделители — табуляция, `;` или `,`.

## Назначение мест

1. Выберите зрителя в списке, затем щёлкните по креслу.
2. Повторный щелчок по тому же креслу снимает назначение.
3. Щелчок по другому месту пересаживает зрителя, старое место освобождается.
4. Если место занято другим — выбранный зритель занимает его, прежний остаётся без места.
5. Если зритель не выбран, щелчок по занятому креслу выбирает зрителя этого кресла.

Один зритель — не более одного места; одно место — не более одного зрителя.
Место выбранного зрителя подсвечивается рамкой.

## Категории и цвета

Категории создаются автоматически из введённых или загруженных данных, пустая
категория сохраняется как «Без категории». Каждой категории назначается цвет;
поменять его можно щелчком по образцу цвета в Легенде под планом — кресла этой
категории перекрасятся сразу.

## Excel: импорт

Кнопка **«Загрузить шаблон»** читает `.xlsx` и заменяет текущий список.
Читается первый лист: столбец A — ФИО, B — Категория, C — Место.

- строка заголовка может присутствовать — она распознаётся и пропускается;
- пустое значение в столбце C — зритель импортируется без места;
- нераспознанное место — зритель импортируется без места (с уведомлением);
- место понимается как в виде кода (`П-1-5`), так и полным текстом
  («Партер, ряд 1, место 5», «Балкон левый, место 7»);
- если есть лист **«Категории»**, цвета категорий берутся из него;
- если есть лист **«Зал»**, восстанавливается соответствующий зал,
  и коды мест проверяются по его схеме.

### Структура шаблона

**Лист 1** (имя может быть любым):

|   |  A                      | B         | C                     |
|---|---                      |---        |---                    |
| 1 | ФИО                     | Категория | Место                 |
| 2 | Иванова Анна Сергеевна  | Спонсоры  | П-1-5                 |
| 3 | Петров Олег Иванович    | Пресса    | Балкон левый, место 7 |
| 4 | Сидорова Мария Павловна | Волонтёры | *(пусто — без места)* |

**Лист «Категории»** (необязательный): `Категория`, `Цвет` (`#hex`).
**Лист «Зал»** (необязательный): `id зала`, `Имя зала` (например, `sibir`, `КЗ «Сибирь»`).

## Excel: сохранение

- **«Сохранить»** — при поддержке File System Access API (Chrome, Edge) перезаписывает
  ранее открытый файл; иначе работает как скачивание.
- **«Сохранить как»** — всегда предлагает имя файла.

Создаваемая книга:
- лист **«Зрители»**: `ФИО`, `Категория`, `Ряд и место`;
- лист **«Категории»**: `Категория`, `Цвет`;
- лист **«Зал»**: `id зала`, `Имя зала`.

Сохранённый файл можно снова загрузить — данные, цвета и зал восстановятся.

## Печать

Кнопка **«Печать»** печатает только план зала и Легенду. Параметры задаются в
`style.css` в блоке `@media print`:

- размер и ориентация — правило `@page` (например, `@page { size: A4 landscape; margin: 8mm; }`;
  сейчас по умолчанию `A4 portrait
- размер кресла на бумаге — `#plan { --seat: 11px !important; }`
  (для A4 рекомендуется `8px`).

В диалоге печати включите **«Фоновая графика»**, иначе кресла будут белыми.
Зоны не разрываются между страницами (`break-inside: avoid`).

## Команды меню

| Команда | Действие |
|---|---|
| Новый шаблон | Очищает список зрителей и все назначенные места |
| Загрузить шаблон | Заменяет список данными из `.xlsx` |
| Сохранить | Перезаписывает открытый файл или скачивает `.xlsx` |
| Сохранить как | Сохраняет в новый файл с выбором имени |
| Печать | Печатает план зала и легенду |
| Очистить рассадку | Освобождает все места, сохраняя список зрителей |
| Выпадающий список залов | Выбор зала (Театр Драмы, Музкомедия, Филармония, КЗ «Сибирь», Молодёжный) |
| Редактировать/Просмотр | Переключение режима |

## Приватность

Приложение не использует сеть и не отправляет данные на внешние серверы.
Все операции выполняются локально в браузере.

## Поддержка браузеров

- **Chrome / Edge** — полный функционал, включая перезапись файла через
  File System Access API;
- **Firefox / Safari** — полный функционал, кроме перезаписи файла
  («Сохранить» работает как скачивание);
- чтение буфера кнопкой «Прочитать буфер обмена» может потребовать разрешения;
  вставка вручную (Ctrl+V) работает всегда.

## Возможные неполадки

- **«Файл vendor/xlsx.full.min.js не найден»** — библиотека не скачана или лежит
  не в той папке (см. «Установка»).
- **Кресла при печати белые** — включите «Фоновая графика» в диалоге печати.
- **Места из файла не распознались** — проверьте, что в столбце C указана зона и
  номера, существующие в схеме выбранного зала.
- **Значок вкладки не обновился** — перезагрузите страницу (`Ctrl+F5`), браузер  кэширует favicon.
