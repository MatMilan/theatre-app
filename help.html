Рассадка зрителей — инструкция

Локальное приложение для распределения зрителей по местам в залах. Работает офлайн, все данные обрабатываются локально и никуда не отправляются.

Установка и запуск

  1. Рядом с index.html должна быть папка vendor с файлом xlsx.full.min.js (SheetJS).
  2. Откройте index.html двойным щелчком в браузере — сервер не нужен.
Если появляется сообщение «Файл vendor/xlsx.full.min.js не найден» — библиотека не скачана или лежит не в той папке.

Режимы работы

  • Редактирование — виден список зрителей, доступно назначение мест, добавление, правка, удаление, цвета категорий.
  • Просмотр — только меню и план зала; можно рассматривать кресла с подсказками.

После успешных «Сохранить», «Сохранить как» и «Печать» приложение возвращается в режим просмотра. Перед разрушающими действиями запрашивается подтверждение.

Коды мест

Каждое место имеет внутренний код вида ПРЕФИКС-РЯД-МЕСТО, например П-1-5. Префикс однозначно обозначает зону внутри выбранного зала.

  • Для обычных зон: П-1-5 → «Партер, ряд 1, место 5».
  • Для вертикальных зон (ложи, боковые балконы): внутренне ЛЛ-1-3, но в интерфейсе и в Excel показывается без ряда — «Ложа левая, место 3».

Место можно задать тремя способами:

  • короткий код: П-1-5, Б-7-36, А-15-10, ЛЛ-1-3, В-2-3, П1-1-5;
  • полный текст: «Партер, ряд 1, место 5»;
  • название зоны + место для вертикальных: «Балкон левый, место 7».
Совпадение имени/префикса нечувствительно к регистру и выбирается по самому длинному совпадению, поэтому «Балкон левый» не путается с «Балкон», а префикс П1 — с П.

Список зрителей

  • Поля: ФИО, категория, место (или «не назначено»).
  • Поиск — по ФИО и категории, без учёта регистра, по частичному совпадению.
  • Фильтр «Только без места» показывает зрителей без назначенного места.
  • Добавление вручную, редактирование, удаление (с подтверждением).
  • «Вставить список…» — массовое добавление построчно. Формат строки: ФИО, категория, место; разделители — табуляция, ; или ,.

Назначение мест

  1. Выберите зрителя в списке, затем щёлкните по креслу.
  2. Повторный щелчок по тому же креслу снимает назначение.
  3. Щелчок по другому месту пересаживает зрителя, старое место освобождается.
  4. Если место занято другим — выбранный зритель занимает его, прежний остаётся без места.
  5. Если зритель не выбран, щелчок по занятому креслу выбирает зрителя этого кресла.

Один зритель — не более одного места; одно место — не более одного зрителя. Место выбранного зрителя подсвечивается рамкой.

Категории и цвета

Категории создаются автоматически из введённых или загруженных данных; пустая категория сохраняется как «Без категории». Каждой категории назначается цвет. Поменять его можно щелчком по образцу цвета в Легенде под планом — кресла этой категории перекрасятся сразу.

Импорт из Excel

Кнопка «Загрузить шаблон» читает .xlsx и заменяет текущий список. Читается первый лист: столбец A — ФИО, B — Категория, C — Место.

  • строка заголовка может присутствовать — она распознаётся и пропускается;
  • пустое значение в столбце C — зритель импортируется без места;
  • нераспознанное место — зритель импортируется без места (с уведомлением);
  • место понимается и как код (П-1-5), и полным текстом («Партер, ряд 1, место 5»);
  • лист «Категории» — цвета категорий;
  • лист «Зал» — восстанавливает соответствующий зал.

Сохранение в Excel

  • «Сохранить» — при поддержке File System Access API (Chrome, Edge) перезаписывает открытый файл, иначе скачивает.
  • «Сохранить как» — всегда предлагает имя файла.

Создаваемые листы: «Зрители» (ФИО, Категория, Ряд и место), «Категории» (Категория, Цвет), «Зал» (id зала, Имя зала).

Печать

Кнопка «Печать» печатает только план зала и Легенду. Параметры — в style.css в блоке @media print: размер и ориентация листа задаются правилом @page, размер кресла на бумаге — #plan { --seat: … }. Внизу страницы печатается логотип и подпись.

В диалоге печати включите «Фоновая графика», иначе кресла будут белыми.

Приватность

Приложение не использует сеть и не отправляет данные на внешние серверы. Все операции выполняются локально.

Поддержка браузеров

  • Chrome / Edge — полный функционал, включая перезапись файла.
  • Firefox / Safari — полный функционал, кроме перезаписи файла («Сохранить» работает как скачивание).

Возможные неполадки

  • «Файл vendor/xlsx.full.min.js не найден» — библиотека не скачана или лежит не в той папке.
  • Кресла при печати белые — включите «Фоновая графика» в диалоге печати.
  • Места из файла не распознались — проверьте, что зона и номера существуют в схеме выбранного зала.
  • Значок вкладки не обновился — перезагрузите страницу (Ctrl+F5).
